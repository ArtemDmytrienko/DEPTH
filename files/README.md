# DEPTH — шахтёр-рогалик

Небольшая браузерная игра: копаешь вниз, собираешь руду, качаешь апгрейды и оружие,
сражаешься с монстрами и, на глубине 200 метров, с финальным боссом.

Играть онлайн: **https://ТВОЙ_НИК.github.io/depth-game/** *(замени на свою ссылку после публикации через GitHub Pages)*

## Управление

| Клавиша | Действие |
|---|---|
| **A / D** | ходьба влево / вправо |
| **W** | копать/подниматься вверх |
| **S** | копать вниз |
| **J** | атака |
| стрелки, ПРОБЕЛ | дублируют WASD и J (на выбор) |
| **ESC** | вернуться на поверхность |

## Структура проекта

```
depth-game/
├── index.html       — разметка страницы (HUD, оверлеи меню/магазина/титров)
├── style.css        — все стили и цветовая палитра
├── README.md        — этот файл
└── js/
    ├── constants.js — вся "база данных": тайлы, руда, апгрейды, оружие, монстры, босс
    ├── save.js      — сохранение прогресса в localStorage
    ├── world.js     — процедурная генерация пещеры
    ├── player.js    — состояние забега (позиция, кислород, HP), формулы апгрейдов
    ├── combat.js     — монстры (спавн, ИИ), атака, урон
    ├── boss.js      — бой с финальным боссом
    ├── input.js     — клавиатура (WASD/J) + движение и копание
    ├── shop.js      — магазин, оверлеи (смерть/магазин/титры)
    ├── render.js    — вся отрисовка на canvas + HUD
    └── main.js      — главный игровой цикл, запуск игры (подключается последним!)
```

Файлы в `js/` **не обёрнуты** в `(() => {...})()`, поэтому все их функции и
переменные общие — это специально, чтобы можно было делить код на файлы без
сборщика (webpack/vite и т.п.). Из-за этого **порядок подключения `<script>`
в `index.html` важен** — каждый следующий файл использует то, что объявлено в
предыдущих, а `main.js` обязательно должен идти последним.

Картинка на титульном экране встроена прямо в `index.html` как base64
(`data:image/jpeg;base64,...`), отдельным файлом не идёт — это сделано, чтобы
разметку можно было скопировать как один файл при желании.

## Как запустить локально

Никакой сборки не нужно — это обычные HTML/CSS/JS файлы.

1. Скачай или склонируй репозиторий, сохранив структуру папок (особенно `js/`)
2. Просто открой `index.html` в браузере (двойной клик или перетащи в окно браузера)

Прогресс сохраняется в `localStorage` браузера — у каждого игрока свой, никуда
не отправляется.

## Как редактировать

Открой нужный файл в редакторе кода (VS Code, Sublime, даже Блокнот) — никаких
специальных инструментов не нужно, изменения видно сразу после обновления
страницы в браузере (F5).

Где что искать:

| Хочешь изменить | Файл | Что именно |
|---|---|---|
| Урон/характеристики руды | `constants.js` | `TILE_INFO` |
| Шансы выпадения руды по глубине | `world.js` | `genTile()` |
| Апгрейды в магазине (цена, эффект) | `constants.js` | `UPGRADE_DEFS` |
| Оружие (урон, скорость атаки, цена) | `constants.js` | `WEAPON_DEFS` |
| Монстров (здоровье, урон, скорость) | `constants.js` | `MONSTER_DEFS` |
| Босса (здоровье, атаки) | `constants.js` / `boss.js` | `BOSS_DEF` / `updateBoss()` |
| На какой глубине начинается бой с боссом | `constants.js` | `BOSS_TRIGGER_DEPTH` |
| Размер поля, тайлов | `constants.js` | `TILE`, `COLS`, `VISIBLE_ROWS` |
| Управление (клавиши) | `input.js` | `keyLeft()`, `keyRight()`, `keyUp()`, `keyDown()`, `keyAttack()` |

Цвета и внешний вид — в `style.css`, там всё через CSS-переменные в `:root`,
достаточно поменять пару hex-кодов, чтобы перекрасить всю игру.

## Известные ограничения / что можно доделать

- Прогресс не синхронизируется между устройствами (это `localStorage`, он локальный)
- Баланс (урон, здоровье монстров и босса) подобран на глаз — можно и нужно тестировать и подстраивать
- Нет звука
- Только один босс на глубине 200м
