# DEPTH — шахтёр-рогалик

Небольшая браузерная игра: копаешь вниз, собираешь руду, качаешь апгрейды и оружие,
сражаешься с монстрами и, на глубине 200 метров, с финальным боссом.

Играть онлайн: **https://ТВОЙ_НИК.github.io/depth-game/** *(замени на свою ссылку после публикации через GitHub Pages)*

## Структура проекта

```
depth-game/
├── index.html   — разметка страницы (HUD, оверлеи меню/магазина/титров)
├── style.css    — все стили и цветовая палитра
├── script.js    — вся игровая логика
└── README.md    — этот файл
```

Картинка на титульном экране встроена прямо в `index.html` как base64
(`data:image/jpeg;base64,...`), отдельным файлом не идёт — это сделано, чтобы
игру можно было целиком скопировать одним файлом при желании.

## Как запустить локально

Никакой сборки не нужно — это обычные HTML/CSS/JS файлы.

1. Скачай или склонируй репозиторий
2. Просто открой `index.html` в браузере (двойной клик или перетащи в окно браузера)

Прогресс сохраняется в `localStorage` браузера — у каждого игрока свой, никуда
не отправляется.

## Как редактировать

Открой любой из трёх файлов в редакторе кода (VS Code, Sublime, даже Блокнот) —
никаких специальных инструментов не нужно, изменения видно сразу после
обновления страницы в браузере (F5).

Где что искать в `script.js`:

| Хочешь изменить | Ищи в коде |
|---|---|
| Урон/характеристики руды | `TILE_INFO` |
| Шансы выпадения руды по глубине | `genTile()` |
| Апгрейды в магазине (цена, эффект) | `UPGRADE_DEFS` |
| Оружие (урон, скорость атаки, цена) | `WEAPON_DEFS` |
| Монстров (здоровье, урон, скорость) | `MONSTER_DEFS` |
| Босса (здоровье, атаки) | `BOSS_DEF` и `updateBoss()` |
| На какой глубине начинается бой с боссом | `BOSS_TRIGGER_DEPTH` |
| Размер поля, тайлов | `TILE`, `COLS`, `VISIBLE_ROWS` |

Цвета и внешний вид — в `style.css`, там всё через CSS-переменные в `:root`,
достаточно поменять пару hex-кодов, чтобы перекрасить всю игру.

## Известные ограничения / что можно доделать

- Прогресс не синхронизируется между устройствами (это `localStorage`, он локальный)
- Баланс (урон, здоровье монстров и босса) подобран на глаз — можно и нужно тестировать и подстраивать
- Нет звука
- Только один босс на глубине 200м
